# Contributing

We'd love to have new people contribute to Essence! But we do have some rules:

- No typing! Typing makes Luau inefficient and slower. Besides, if you know what you are making, it should not be an issue
- AI
    - AI is welcome (and encouraged) here. 
    - Do __not__ be useless. Know what code has been written, be able to justify it.
- ASD-STE100
    We use the ASD-STE100 so that people are able to make clear understanding of what goes on. This is primarily for documentation clarity and for non-english speakers.
